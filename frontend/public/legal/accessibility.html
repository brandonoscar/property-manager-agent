Occupella

Accessibility

Last updated: September 8, 2026

Occupella is a property-management platform operated by Oscar Ventures LLC. This page says what we have actually built for accessibility and — just as important — what we have not tested. We would rather you knew the second list before you depend on the product than after.

1. What we do not claim

We do not claim WCAG 2.1 AA conformance, and we have not published a VPAT. Both are specific, testable assertions, and we have not run the tests that would let us make them honestly. If you need a formal conformance statement for a procurement process, write to us and we will tell you exactly where we are rather than sending you a document we cannot stand behind.

2. What is built and working

These are deliberate and in the product today:

  • Keyboard focus is always visible. Every interactive element takes a visible focus ring; we do not remove outlines.
  • A skip-to-content link is the first thing in the tab order, so you are not required to tab through the whole sidebar to reach the page.
  • Colour is never the only signal. Where state is shown in colour — password requirements, status pills — a shape, glyph or word carries the same meaning.
  • Reduced motion is respected. If your system asks for less animation, the interface stops animating.
  • Errors are announced. Form errors and the agent's status use live regions, so they are read out rather than only appearing.
  • Every page has its own title, so browser history and tab switching are usable.
  • The interface works at browser zoom, and text scales with it.

3. What we know is not good enough yet

Named individually, because "some areas may not be fully accessible" tells you nothing:

  • No screen-reader pass has been run. Nobody has driven Occupella end to end with VoiceOver, NVDA or JAWS. Parts will be wrong and we do not yet know which parts.
  • Colour contrast is now measured, and one token fails. Every colour in the palette was checked against the page background on 8 September 2026. Body text, links, error text and the warning colour all clear the AA bar of 4.5:1 — most of them comfortably. The faintest grey used for hints and captions does not: it measures 2.61:1, which is below even the 3:1 bar that applies to large text. Where that grey carried something you have to read — the unmet password rules — it has been changed to a colour that passes. Everywhere else it is still there, because every value dark enough to pass is darker than the grey one step above it, and fixing that properly means re-spacing the whole scale rather than patching one value. That is scheduled, not forgotten, and the measurement now runs on every change so it cannot quietly get worse.
  • Tap-target sizes are measured against one bar and not the other. Every button and link that states its own height was checked on 8 September 2026. One was below the 24×24 minimum that WCAG 2.2 requires at the level we aim for — a small dismiss button, now enlarged. Many are below the separate 44×44 guideline, which is a stricter bar we do not claim: this is a dense desktop tool with tables that put a lot on screen at once, and 44 pixels everywhere would change what it is. Roughly 120 more controls take their size from spacing rather than stating it, and those can only be measured on a real device, which has not been done.
  • Tab order has not been audited across the whole app, only on the sign-in and password screens.
  • Some forms label their fields with placeholder text alone, which disappears once you start typing and is not a substitute for a label.
  • Modal focus is now held, with one deliberate exception. Dialogs keep the keyboard inside them and give focus back to whatever opened them when they close; Escape closes every one, including the connector panels, where it previously did nothing. The exception is the narrow-screen navigation drawer: it is the same element as the desktop sidebar, so trapping focus there could strand somebody who resizes their window. Escape and tapping outside both close it.
  • The product walkthrough video has no captions or transcript.
  • The interface is English only, with US date, number and address formats.

4. If something is unusable, tell us

Email team@occupella.com with what you were trying to do, the page you were on, and the assistive technology you were using if any. A person reads that inbox.

We will reply, and if the fix is small we would rather ship it than add it to a list. If you are blocked from something you are entitled to do in your own account, say so plainly in the subject line and we will treat it that way — the point of this page is that you should not have to argue for it.

5. How this page changes

Every line in section 3 moves to section 2 only when somebody has run the relevant test, and the date at the top changes when it does. We will not quietly upgrade a claim because the code looks better.
